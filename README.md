# Bulls and Cows

A C# console implementation of the Bulls and Cows game.

The program generates a 4-digit secret number with unique digits and
allows the player to submit guesses. Each valid guess receives Bulls
and Cows feedback.

Supported commands:
- n / new - start a new game
- h / history - show the current game's guess history
- q / quit / exit - quit the program

## Changes from the specification
When the history is empty, the program prints "No guesses yet."
